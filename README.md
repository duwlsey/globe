# Globe explorers

A three-country classroom quiz: Brazil, Kenya, and Rwanda.

Start from South Korea. Click or press Space, Enter, an arrow key, or a presentation remote to advance through the globe, letter-count hint, first letter, flag, answer, and next country.

Open `index.html` in a browser, or visit the GitHub Pages deployment.

This is a static, buildless site. All runtime assets are local.
